# Fanatics — 08 Stremiium Implications (ADOPT / ADAPT / AVOID / BEAT)

Applied to the Stremiium **phygital collectibles + FanCash-style loyalty** line (Brief §7
filter).

## ADOPT

| # | Finding | Stremiium action |
|---|---|---|
| A1 | **Unified customer identity across verticals** | Adopt: one NeoBank identity powering banking, collectibles, prediction/DFS, and rewards. |
| A2 | **Cross-vertical loyalty currency (FanCash model)** | Adopt the *pattern* via `$STM` + FanCash-style credit: earn in one vertical, redeem across all. |
| A3 | **Earn-on-purchase %-back** | Adopt %-back earning on spend across verticals to drive attach. |
| A4 | **Live-commerce engagement** | Adapt a digital/phygital drop mechanic (streamed collectible releases) to drive engagement. |

## ADAPT

| # | Finding | Stremiium change |
|---|---|---|
| D1 | Closed, non-tradable FanCash | Adapt: `$STM` adds on-chain utility (25% fee discount, buy-back/burn) while keeping redemption spend-first. |
| D2 | Physical-goods heavy model | Adapt to **digital-first/phygital**: token + optional physical fulfilment via partners, avoiding inventory drag. |
| D3 | Global IP licensing cost | Adapt: focus on **SA-relevant rights** (local leagues) + non-IP collectibles. |
| D4 | Cross-vertical data combination | Adapt under strict **POPIA purpose limitation** + consent. |

## AVOID

| # | Finding | Why Stremiium refuses it |
|---|---|---|
| V1 | Physical inventory/fulfilment as core | Capital-heavy and outside a digital NeoBank's natural scope. |
| V2 | Uncontrolled cross-vertical data merging | POPIA/privacy liability. |
| V3 | Betting-promotion crowding fan engagement | Problem-gambling and reputational risk. |
| V4 | Tradable loyalty currency without utility framing | Securities/CASP classification trap. |

## BEAT

| # | Competitor weakness | How Stremiium beats it |
|---|---|---|
| B1 | Closed currency, no on-chain settlement | `$STM` adds programmatic buy-back/burn + fee utility → transparent, verifiable value. |
| B2 | Physical-heavy margin structure | Digital-first = higher margin, faster scale. |
| B3 | Privacy-scrutiny cross-vertical model | POPIA-native data governance + `af-south-1` residency. |
| B4 | Separate commerce/betting apps | One NeoBank app unifies banking + collectibles + rewards + prediction. |

## Net strategic verdict

Fanatics is the **cross-vertical loyalty and identity** blueprint — the single best
reference for Stremiium's "one rewards engine across verticals" ambition. Adopt its
unified-identity + shared-currency loop, adapt it to a digital-first, `$STM`-powered,
POPIA-native NeoBank, avoid its physical-inventory and unconstrained-data liabilities, and
beat it on on-chain transparency and unified UX.
