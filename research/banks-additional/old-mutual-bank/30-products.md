# Old Mutual Bank (OM Bank) — Products

All [OBS] unless noted.

## 1. Core proposition

| Feature | Detail | Tag |
|---|---|---|
| Account model | Pay-as-you-use bank account from **R4.95/month** | [OBS] |
| Card | **Visa debit** card (virtual + physical); virtual card details in-app | [OBS] |
| Savings | Savings account R0 monthly fee; interest up to **7.23% p.a.** (nominal) | [OBS] |
| Rewards | **2.5% back in points** on qualifying debit-card spend | [OBS] |
| Features | Goal-setting, automated deposits, real-time insights and "nudges" | [OBS] |
| Credit | Fast in-app credit decisions | [OBS] |
| Transparency | "No hidden fees" — transparent pricing | [OBS] |
| ATM access | No own ATMs; uses other banks' ATMs | [OBS] |
