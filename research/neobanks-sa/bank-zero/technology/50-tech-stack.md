# Bank Zero — Technology Stack

## 1. Core infrastructure
- Runs on **IBM Z mainframe** and **LinuxONE** as a secure platform, using **IBM Secure Service Container** to help protect against data breaches [OBS] — [Lesaka newsroom](https://lesakatech.com/newsroom-all/bank-zero-snapped-up-for-r1-1-billion)
- Fully digital, **no physical branches**; operation via mobile app (Android + iOS) [OBS] — [Lesaka newsroom](https://lesakatech.com/newsroom-all/bank-zero-snapped-up-for-r1-1-billion)

## 2. Card security technology
- **Patented debit card security architecture** — card data changes to limit fraud during transactions [OBS] — [VaultCue](https://vaultcue.com/accounts/bank-zero/review/), [CreditDeals](https://creditdeals.io/za/debit-cards/bankzero)

## 3. Processing / partnerships
- Partnership with **Paymentology** (April 2026) to prepare for the card/processing model supporting the Mukuru migration [OBS] — [itnewsafrica](https://www.itnewsafrica.com/industries/fintech_news/bank-zero-profit/)
- Prepares for **alliance-banking** integrations (live January 2026) [OBS] — [TechCabal](https://techcabal.com/2026/09/22/bank-zero-break-even-alliance-partnerships/)

## 4. App
- App-only banking with app-based account opening [OBS] — [VaultCue](https://vaultcue.com/accounts/bank-zero/review/)
- Multi-user business authorisations and automated invoicing built into the app [OBS] — same source
