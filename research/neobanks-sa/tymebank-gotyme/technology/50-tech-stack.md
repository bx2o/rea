# TymeBank / GoTyme Bank — Technology Stack

## 1. Cloud & hosting
- Fully **cloud-native**, hosted on **Amazon Web Services (AWS)**; core banking migrated to AWS since 2018 [OBS] — [TymeBank Fintech Story](https://www.tymebank.co.za/content/uploads/2019/02/TymeBank-Fintech-Story.pdf)
- Migrated **85% of core operations to the cloud** within six months, resulting in ~50% reduction (cost/overhead) [OBS] — [Mambu case study](https://mambu-hotfix.8west.ie/en/customer/tyme-bank)
- Containerised setup using **Amazon ECS and Amazon EKS** for mission-critical services [OBS] — [Grokipedia/TymeBank](https://grokipedia.com/page/TymeBank)

## 2. Core banking
- **Mambu** SaaS core banking system (cloud-native ledger) hosted on AWS — "highly secure ledger for customers' accounts" [OBS] — [Mambu case study](https://mambu-hotfix.8west.ie/en/customer/tyme-bank), [TymeBank Fintech Story](https://www.tymebank.co.za/content/uploads/2019/02/TymeBank-Fintech-Story.pdf)

## 3. Cards & payments processing
- **BPC SmartVista** issuing platform integrated with kiosks and digital channels; open APIs enabled rapid feature rollout [OBS] — [BPC press release](https://www.bpcbt.com/en/press/from-zero-to-12-million-customers.-a-decade-long-partnership-of-gotyme-bank-and-bpc-drives-south-african-digital-adoption)

## 4. Distribution / onboarding technology
- Kiosk onboarding with biometric verification; account opening <5 minutes [OBS] — [Grokipedia/TymeBank](https://grokipedia.com/page/TymeBank)

## 5. Channels
- Mobile app + mobile-friendly internet banking (no branches) [OBS] — [TymeBank Fintech Story](https://www.tymebank.co.za/content/uploads/2019/02/TymeBank-Fintech-Story.pdf)
- **Old TymeBank app discontinued** at rebrand; customers migrate to the **GoTyme Bank app** (existing credentials carry over) [OBS] — [MoneyToday](https://moneytoday.co.za/banking/tymebank-internet-banking)

## 6. Engineering footprint
- Product development & engineering hub in **Ho Chi Minh City, Vietnam** (300+ staff) [OBS] — [Tyme newsroom](https://www.tyme.com/news-room/tyme-secures-new-international-investors-in-latest-capital-raise-with-more)
