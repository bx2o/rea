# EasyEquities — Products & Fees

> **Fees/limits change.** Values below are from EasyEquities cost profiles and help centre as at **2026-10-16**. Re-verify at source.

## 1. Products / account types

| Product | Description | Tag |
|---|---|---|
| **ZAR Account** | Core JSE + fractional share investing | [OBS] |
| **TFSA** | Tax-Free Savings Account — R46,000/yr (older: R36,000), R500,000 lifetime | [OBS] |
| **RA Account** | Retirement Annuity | [OBS] |
| **Offshore accounts** | **USD, AUD, GBP, EUR** accounts (global shares/ETFs) | [OBS] |
| **EasyFX** | In-platform currency conversion ZAR↔USD/AUD/GBP/EUR | [OBS] |
| **EasyProperties** | Fractional property investing | [OBS] |
| **Demo accounts** | ZAR & USD practice accounts | [OBS] |
| **Fractional shares** | Buy from ~R1 | [OBS] |
| Crypto | Some reviews list crypto exposure; scope unclear | [UNVERIFIED] |

## 2. Fee schedule (indicative)

| Item | Fee | Tag |
|---|---|---|
| Brokerage (ZAR, per transaction) | **0.25%** (min 1c per one source; R10 min per another) | [OBS]/[UNVERIFIED min] |
| Registration / minimums | None | [OBS] |
| Thrive platform fee | **R25/month** (waived at Thrive Level 3, or under 21 / over 65) | [OBS] |
| **USD account commission** | 0.25% buy/sell | [OBS] |
| USD clearing/administration | 0.31% | [OBS] |
| USD SEC fee | 0.00218% (sell) | [OBS] |
| FX fee (offshore) | 0.5% + 2% above morning spot rate | [OBS] |
| EasyProperties platform fee | 0.6% of AUM; 1.0% IPO fee; 1.5% brokerage | [OBS] |

## 3. TFSA limits

- Annual: **R46,000** (increased from R36,000). Lifetime: **R500,000**. Withdrawals do **not** reset limits. [OBS]
