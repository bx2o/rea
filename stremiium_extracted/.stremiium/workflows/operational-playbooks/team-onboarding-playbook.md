# Team Onboarding Playbook

**Purpose**: Standardized process for onboarding new team members  
**Trigger**: New hire first day  
**Owner**: HR + Hiring Manager  
**Last Updated**: February 18, 2026

---

## Pre-Onboarding (Before Day 1)

### Preparation

- [ ] Background check completed
- [ ] Offer letter signed
- [ ] Welcome email sent
- [ ] Equipment ordered (laptop, monitor, etc.)
- [ ] Accounts created (email, Slack, GitHub)
- [ ] Access provisioned
- [ ] Workspace prepared
- [ ] First week calendar blocked

---

## First Day

### Morning (Arrival & Orientation)

```
1. Welcome & introductions
2. Office tour
3. Benefits/payroll paperwork
4. Equipment setup
5. System introduction
6. Team intro lunch
```

### Afternoon (Technical Onboarding)

```
1. IT setup: VPN, credentials, tools
2. Repository access & local setup
3. Development environment setup
4. First commit/PR (usually documentation)
5. Meet mentors/team
6. Week overview
```

### Tools Access

- [ ] Email account
- [ ] Slack
- [ ] GitHub
- [ ] Communication tools (Zoom, etc.)
- [ ] Collaboration (Docs, Wikis)
- [ ] JIRA/project management

---

## First Week

### Curriculum (Self-paced + mentoring)

```
Day 1
- Welcome & orientation
- Company overview
- Team introduction

Day 2-3
- Codebase exploration
- First small PR
- System architecture overview

Day 4-5
- Development environment mastery
- First assigned task
- Team meetings/standups
```

### Relationships

- [ ] Meet manager (daily check-in)
- [ ] Meet mentor/buddy (technical)
- [ ] Meet team (welcome lunch)
- [ ] Meet cross-team (brief coffee chats)

### Learning

- [ ] Company handbook
- [ ] System architecture document
- [ ] Development setup guide
- [ ] Company mission/values

---

## First 30 Days

### Week 2-3

- Continue with small tasks
- Pair programming sessions
- Code review participation
- Meeting attendance

### Week 4

- First larger feature
- Increased independence
- Relationship building
- 30-day check-in with manager

### Ramp-Up Targets

- Day 1: Environment set up
- Week 1: Understand architecture
- Week 2: Small PR merged
- Week 3: Feature task assigned
- Week 4: Productivity ~ 50%

---

## 30-Day Check-in

### Manager Discussion

- How is onboarding going?
- Clear understanding of role?
- Team relationships good?
- Blockers or concerns?
- Adjustments needed?

### Peer Feedback

- Quick check-in with team
- Integration level?
- Has peer provided help?
- Anything to improve?

---

## Success Criteria

- [ ] Environment fully set up
- [ ] Can build/deploy locally
- [ ] 1+ PR merged
- [ ] Positive team feedback
- [ ] Understanding of codebase
- [ ] Comfortable with team
- [ ] Knows escalation path
