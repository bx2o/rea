# The Artisan - Design & Creative Workflows

**Agent**: The Artisan 🎨  
**Domain**: Design, UX, creative direction, visual identity  
**Purpose**: Design work, creative direction, copywriting, user experience

---

## Workflow 1: Visual Design & Branding Workflow

### Trigger

- New visual identity needed
- Brand refresh required
- Design system creation
- Product design project started

### Process

#### Step 1: Understand Design Requirements

**Goal**: Clarify design brief  
**Actions**:

- Understand project goals
- Identify target audience
- Review brand guidelines (if existing)
- Gather inspiration
- Document requirements
- Create design brief

**Success Criteria**:

- ✅ Design brief comprehensive
- ✅ Goals crystal clear
- ✅ Audience understood
- ✅ Creative freedom defined

**Duration**: 1-2 hours

---

#### Step 2: Research & Inspiration

**Goal**: Gather design inspiration  
**Actions**:

- Competitive analysis
- Trend research
- Mood board creation
- Reference collection
- User research (if applicable)
- Document insights

**Success Criteria**:

- ✅ Strong inspiration sources
- ✅ Trends understood
- ✅ Direction clear

**Duration**: 2-3 hours

---

#### Step 3: Concept Development

**Goal**: Create initial design concepts  
**Actions**:

- Ideate multiple directions
- Create design concepts (3-5)
- Sketch / wireframe
- Develop visual language
- Consider variations
- Prepare concepts for review

**Success Criteria**:

- ✅ Diverse concepts created
- ✅ Visual direction clear
- ✅ Options to choose from

**Duration**: 4-6 hours

---

#### Step 4: Review & Refine

**Goal**: Get feedback and improve  
**Actions**:

- Present concepts to stakeholders
- Gather feedback
- Identify preferred direction
- Refine selected concept
- Develop into full design
- Iterate based on feedback

**Success Criteria**:

- ✅ Direction selected
- ✅ Design refined
- ✅ Stakeholder satisfied

**Duration**: 2-3 hours + revisions

---

#### Step 5: Finalize & Handoff

**Goal**: Complete design for implementation  
**Actions**:

- Finalize all design details
- Create design specifications
- Prepare design assets
- Document color palette
- Prepare typography specs
- Create design system/guidelines

**Success Criteria**:

- ✅ Design complete
- ✅ Specs detailed
- ✅ Assets ready
- ✅ Developer handoff smooth

**Duration**: 2-3 hours

---

### Outcomes

- ✅ Visual design complete
- ✅ Design system established
- ✅ Brand guidelines updated
- ✅ Implementation ready
- ✅ Assets documented

## Workflow 2: User Experience (UX) Design Workflow

### Trigger

- New product/feature UX needed
- Usability issues identified
- User feedback indicates redesign needed
- Analytics show conversion problems

### Process

#### Step 1: User Research

**Goal**: Understand users  
**Actions**:

- Define user personas
- Conduct user interviews (5-8)
- User observation/testing
- Create user journey maps
- Identify pain points
- Document requirements

**Success Criteria**:

- ✅ Users deeply understood
- ✅ Pain points identified
- ✅ Journeys documented

**Duration**: 4-6 hours

---

#### Step 2: Design Solutions

**Goal**: Create wireframes and mockups  
**Actions**:

- Create user flows
- Wireframe key screens
- Create information architecture
- Design interaction patterns
- Plan user journey
- Create prototype if complex

**Success Criteria**:

- ✅ Design clear
- ✅ Flows intuitive
- ✅ Pain points addressed

**Duration**: 6-10 hours

---

#### Step 3: User Testing

**Goal**: Validate design with users  
**Actions**:

- Create test scenarios
- Recruit test users (5-8)
- Conduct usability testing
- Gather feedback
- Identify issues
- Document findings

**Success Criteria**:

- ✅ Design validated
- ✅ Issues identified
- ✅ Improvements clear

**Duration**: 4-6 hours

---

#### Step 4: Iterate & Refine

**Goal**: Improve based on feedback  
**Actions**:

- Make refinements
- Address usability issues
- Re-test problematic areas
- Gather additional feedback if needed
- Finalize design
- Prepare for handoff

**Success Criteria**:

- ✅ UX improved
- ✅ Usability validated
- ✅ Design ready

**Duration**: 3-4 hours

---

#### Step 5: Handoff & Implementation

**Goal**: Enable development  
**Actions**:

- Create design handoff document
- Prepare design assets
- Document interaction patterns
- Create style guide
- Review with development
- Support during development

**Success Criteria**:

- ✅ Implementation smooth
- ✅ Developer questions answered
- ✅ Fidelity maintained

**Duration**: 1-2 hours handoff + support

---

### Outcomes

- ✅ User-centered design created
- ✅ Usability validated
- ✅ Pain points addressed
- ✅ Implementation ready
- ✅ User satisfaction improved

## Workflow 3: Copywriting & Content Strategy Workflow

### Trigger

- New copy needed (website, marketing, product)
- Content strategy required
- Messaging alignment needed
- Brand voice inconsistency

### Process

#### Step 1: Define Brief & Strategy

**Goal**: Understand what to write  
**Actions**:

- Define copy purpose
- Identify target audience
- Clarify key messages
- Determine tone/voice
- Create content brief
- Plan distribution

**Success Criteria**:

- ✅ Brief comprehensive
- ✅ Messaging clear
- ✅ Audience understood
- ✅ Voice defined

**Duration**: 1-2 hours

---

#### Step 2: Research & Gather Input

**Goal**: Understand topic deeply  
**Actions**:

- Competitive analysis
- Understand product/service
- Interview SMEs
- Gather customer testimonials
- Research audience needs
- Document facts/features

**Success Criteria**:

- ✅ Knowledge comprehensive
- ✅ Key points identified
- ✅ Perspective clear

**Duration**: 2-3 hours

---

#### Step 3: Write & Draft

**Goal**: Create copy  
**Actions**:

- Create headlines
- Write body copy
- Craft CTAs
- Maintain brand voice
- Consider SEO (if needed)
- Create multiple variations

**Success Criteria**:

- ✅ Copy compelling
- ✅ Message clear
- ✅ Brand voice consistent
- ✅ Variations ready

**Duration**: 4-8 hours

---

#### Step 4: Review & Refine

**Goal**: Polish copy  
**Actions**:

- Self-edit for clarity
- Peer review
- SME review (if needed)
- Test messaging (if possible)
- Incorporate feedback
- Finalize for approval

**Success Criteria**:

- ✅ Copy polished
- ✅ Feedback integrated
- ✅ Ready for release

**Duration**: 2-3 hours + revisions

---

#### Step 5: Publish & Monitor

**Goal**: Release and track performance  
**Actions**:

- Publish copy
- Share with team
- Monitor performance
- Track engagement
- Gather feedback
- Plan iterations

**Success Criteria**:

- ✅ Copy published
- ✅ Performance good
- ✅ Response positive

**Duration**: Ongoing monitoring

---

### Outcomes

- ✅ Compelling copy written
- ✅ Brand voice consistent
- ✅ Messaging clear
- ✅ Published and performing
- ✅ Audience engaged

## Workflow 4: Design System & Pattern Library Workflow

### Trigger

- Design consistency issues
- Multiple products need unified branding
- Scale requires design system
- Developer/designer collaboration needs improvement

### Process

#### Step 1: Audit Current Design

**Goal**: Understand design landscape  
**Actions**:

- Document all existing designs
- Identify components
- Note inconsistencies
- Catalog colors/typography
- Identify patterns
- Engage stakeholders

**Success Criteria**:

- ✅ Current state documented
- ✅ Inconsistencies cataloged
- ✅ Stakeholders aligned

**Duration**: 3-4 hours

---

#### Step 2: Define Design System

**Goal**: Create system foundation  
**Actions**:

- Define design principles
- Create component library
- Define color system
- Create typography system
- Define spacing/layout grid
- Document guidelines

**Success Criteria**:

- ✅ System comprehensive
- ✅ Principles clear
- ✅ Components well-defined

**Duration**: 8-12 hours

---

#### Step 3: Create Pattern Library

**Goal**: Document reusable patterns  
**Actions**:

- Create component specifications
- Document usage rules
- Create visual examples
- Document accessibility
- Create code examples
- Build documentation site

**Success Criteria**:

- ✅ Patterns documented
- ✅ Examples clear
- ✅ Easy for devs to use

**Duration**: 6-8 hours

---

#### Step 4: Socialize & Train

**Goal**: Get adoption  
**Actions**:

- Conduct workshops
- Create training materials
- Share design system
- Gather feedback
- Show value/benefits
- Celebrate adoption

**Success Criteria**:

- ✅ Team trained
- ✅ System adopted
- ✅ Adoption growing

**Duration**: 2-3 hours + ongoing

---

#### Step 5: Maintain & Evolve

**Goal**: Keep system current  
**Actions**:

- Regular reviews
- Add new patterns as needed
- Update existing patterns
- Gather team feedback
- Version and document changes
- Plan future iterations

**Success Criteria**:

- ✅ System actively maintained
- ✅ Team using consistently
- ✅ Quality improving

**Duration**: Ongoing

---

### Outcomes

- ✅ Design system created
- ✅ Pattern library comprehensive
- ✅ Team trained
- ✅ Consistency improved
- ✅ Development speed increased
