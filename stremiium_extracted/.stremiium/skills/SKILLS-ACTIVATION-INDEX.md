## Activation Rules & Workflow

### Rule 1: Keyword Matching

When user input contains ANY keyword from a skill:

- Mark skill as **"Auto-Activated"**
- Load skill into execution context
- Apply skill to response generation

### Rule 2: Context Matching

When user context implies need for skill:

- Mark as **"Context-Activated"**
- Load skill for consideration
- Consider in response generation

### Rule 3: Priority Escalation

When multiple skills match:

1. Highest match count wins (most keywords triggered)
2. If tie, use expertise level (Expert > Advanced > Intermediate)
3. If still tie, use recency (recently used > new)

### Rule 4: Skill Combination

When multiple skills activate:

- Create **Skill Bundle** (complementary skills)
- Apply in sequence
- Example: "Database Design" + "PostgreSQL" + "Security"

### Rule 5: De-Activation

Skills de-activate when:

- User changes topic completely
- Context no longer requires expertise
- Conversation moves to different domain
