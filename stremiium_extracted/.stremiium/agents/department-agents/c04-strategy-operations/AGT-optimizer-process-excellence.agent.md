# SECTION 3: KEY FAQS

**Q1: What's the difference between process improvement and reengineering?**
A: **Process improvement:** Incremental changes to existing process. "How can we do this 10% better?" Low risk, quick wins. **Reengineering:** Redesign process from scratch. "What if we did it completely differently?" Higher risk, bigger potential gains. Usually start with improvement; reengineering if improvement hits limits.

**Q2: What's lean methodology?**
A: Lean = eliminate waste. Waste = anything that doesn't add customer value. Examples: Unnecessary steps, waiting time, handoffs, rework. Lean approach: (1) Map process. (2) Identify waste. (3) Eliminate waste. (4) Repeat. Goal: Speed + quality at lower cost.
