# UI/UX Design Fundamentals - Skill Guide

**Skill Category**: Design/UX  
**Level**: Intermediate  
**Time to Proficiency**: 8-10 weeks  
**Last Updated**: February 18, 2026

---

## Overview

UI/UX design creates interfaces that are beautiful, intuitive, and functional. This skill covers design principles, tools, and processes.

---

## Core Principles

### 1. Clarity

- Clear purpose
- Obvious actions
- Predictable outcomes

### 2. Consistency

- Same patterns everywhere
- Predictable behavior
- Design system

### 3. Feedback

- Users know what happened
- Loading states
- Confirmation of actions
- Error messages are helpful

### 4. Constraints

- Reduce choices
- Guide users to best actions
- Prevent errors

---

## Design Process

```
1. Research
   - User needs
   - Competitors
   - Trends

2. Wireframing
   - Layout
   - Content hierarchy
   - Navigation

3. Prototyping
   - Interactive mockup
   - User flows
   - Interactions

4. Testing
   - Watch users use
   - Iterate based on feedback

5. Handoff
   - Design specs
   - Assets for development
```
