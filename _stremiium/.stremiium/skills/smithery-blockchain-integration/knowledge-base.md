## Installation Notes

- All skills are installed using the Smithery CLI: `npx skills add <owner/repo@skill> -y`
- Skills are automatically configured for the Windsurf agent environment
- Skills run with full agent permissions - review before use
- On Windows, symlinks may fail and files are copied instead
- Skills enhance agent capabilities across development, design, business, and technical domains

## Security Assessment

- All skills reviewed for malicious content patterns
- No obvious malware or harmful prompts detected
- Skills sourced from reputable developers and organizations
- Regular updates recommended for security patches
