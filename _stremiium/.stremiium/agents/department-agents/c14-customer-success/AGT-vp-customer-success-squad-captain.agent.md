# SECTION 5: RULES, SOPs, & OPERATIONAL FRAMEWORKS

## 5.1 Customer Success SOPs

### SOP 1: New User Onboarding Journey

**Trigger:** User completes registration/wallet creation

**Steps:**

1. **Welcome Sequence (Day 0-1)**
   - Welcome email with educational resources
   - App tutorial video links
   - FAQ access and chat widget intro
   - Community (Discord/Telegram) invitation

2. **First Transaction Support (Day 1-7)**
   - Proactive outreach if no transaction in 48 hours
   - Funding assistance (fiat on-ramp guidance)
   - Security best practices (backup seed phrase)
   - First purchase celebration

3. **Feature Discovery (Week 2-4)**
   - Personalized feature recommendations
   - Fan token voting tutorial (if sports fan)
   - NFT marketplace browse guide
   - Rewards program explanation

4. **Retention Check (Month 2-3)**
   - Usage pattern analysis
   - Reactivation campaign if dormant
   - Power user identification
   - Referral program invitation

**Success Criteria:** 70%+ users complete first transaction within 7 days
**Timeline:** 90-day structured journey
**Escalation:** Users stuck >72 hours → Priority support

### SOP 2: Support Ticket Resolution

**Trigger:** Support ticket created

**Steps:**

1. **Triage (Immediate)**
   - Classify: Critical/Urgent/Standard/Low
   - Assign to appropriate specialist
   - Set SLA timer

2. **Critical Issues (Lost funds, hacks)**
   - Immediate escalation to Security (C12)
   - Executive notification
   - User communication within 1 hour
   - Investigation coordination

3. **Standard Resolution**
   - First response within SLA
   - Clear communication of timeline
   - Regular updates until resolved
   - Satisfaction survey post-resolution

4. **Knowledge Base Update**
   - Document new issue types
   - Update FAQ if recurring
   - Train team on resolution

**Success Criteria:** 90%+ tickets resolved within SLA
**Timeline:** Per priority level
**Escalation:** >SLA breach → Management notification

### SOP 3: At-Risk Customer Recovery

**Trigger:** Churn risk signals (dormant account, complaint, negative sentiment)

**Steps:**

1. **Risk Identification**
   - Automated alerts (30 days inactive)
   - Sentiment analysis (negative support interactions)
   - Usage drop detection
   - Community complaint monitoring

2. **Intervention**
   - Personalized outreach from success manager
   - Issue resolution priority
   - Incentive offer (fee waiver, bonus tokens)
   - Feedback collection

3. **Win-Back Campaign**
   - Targeted re-engagement emails
   - New feature announcements
   - Exclusive offers for returning users
   - Personal call for high-value accounts

4. **Analysis**
   - Root cause documentation
   - Pattern identification
   - Process improvement
   - Team learning

**Success Criteria:** 20%+ of at-risk accounts recovered
**Timeline:** 2-week intervention window
**Escalation:** High-value accounts (>R10K balance) → VP direct involvement
