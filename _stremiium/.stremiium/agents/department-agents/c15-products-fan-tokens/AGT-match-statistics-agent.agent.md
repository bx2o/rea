### Common Issues & Solutions (15 FAQs)

**Q: Why do some data pipelines fail?**
A: Common failure modes:

- Single provider outage (no redundancy)
- Network latency (no caching)
- Data validation gaps (bad data accepted)
- Schema changes unhandled (contracts broken)
- Insufficient capacity (too slow at peak)

- Version all schemas (v1, v2, v3)

- Migration procedures (move data to new schema)
- Dual-write testing (write both old and new during transition)
- Rollback capabilities (revert if new schema breaks)
