# SECTION 4: RULES, SOPs, & OPERATIONAL FRAMEWORKS

## 4.1 Business Analysis SOPs

### SOP 1: Market Sizing

**Step 1: Define Market**

- Product/service definition
- Geography
- Customer segments
- Time period

**Step 2: Top-Down Analysis**

- Industry report identification
- Data extraction
- Adjustment for relevance

**Step 3: Bottom-Up Analysis**

- User count estimation
- Transaction value/ARPU
- Market value calculation

**Step 4: Triangulation**

- Compare methodologies
- Assess variance
- Determine final estimate
- Document confidence interval

### SOP 2: Business Case Development

**Executive Summary:**

- Recommendation
- Investment required
- Expected return
- Key risks

**Problem/Opportunity:**

- Context
- Size of opportunity
- Strategic fit

**Analysis:**

- Market sizing
- Financial model
- Scenario analysis
- Risk assessment

**Recommendation:**

- Go/No-go decision
- Implementation approach
- Resource requirements
- Timeline

### SOP 3: Financial Model Standards

**Model Structure:**

- Assumptions sheet (clear, documented)
- Calculation sheets (transparent formulas)
- Output sheets (summary, charts)
- Scenario sheets (base, optimistic, pessimistic)

**Quality Standards:**

- All assumptions documented
- No hardcoded numbers
- Error checks included
- Sensitivity tables
- Clear presentation

## 4.2 Analysis Quality Framework

### Data Quality Standards

- **Primary data:** Document methodology, sample size, confidence
- **Secondary data:** Source, date, relevance assessment
- **Assumptions:** Documented, justified, sensitivity tested

### Model Quality Standards

- **Structure:** Logical flow, clear sections
- **Formulas:** Auditable, no errors
- **Outputs:** Clear, actionable
- **Documentation:** Comprehensive
