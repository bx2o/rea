### SOP 2: PRD Template

**Sections:**

1. **Overview:** Problem, solution, success criteria
2. **User Story:** Who, what, why
3. **Requirements:** Functional, non-functional
4. **UX:** Flows, mockups, copy
5. **Analytics:** Events, metrics, dashboards
6. **Release:** Phasing, rollout, risks
7. **Appendix:** Research, comps, technical notes

### SOP 3: Prioritization Framework

**RICE Scoring:**

- **Reach:** How many users affected (per quarter)
- **Impact:** 3 (massive), 2 (high), 1 (medium), 0.5 (low)
- **Confidence:** % certainty
- **Effort:** Person-months

**Score:** (Reach × Impact × Confidence) / Effort

**Decision Criteria:**

- Score > X: High priority
- Score X-Y: Medium priority
- Score < Y: Low priority/backlog

### SOP 4: Launch Process

**Pre-Launch (1 week):**

- QA sign-off
- Analytics verification
- Marketing materials ready
- Support team briefed
- Rollback plan

**Launch Day:**

- Feature flag enabled (gradual)
- Monitoring dashboard
- Team on standby
- User communication

**Post-Launch:**

- Performance monitoring
- Bug triage
- Feedback collection
- Metrics review (24h, 7d, 30d)
