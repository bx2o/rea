# Sources — `[S#]` Reference Map

**How to read the Type column:**
- **STATUTE / REG** — binding primary law or subordinate legislation.
- **REG-GUIDE** — regulator-issued guidance, directive, circular, manual, press release or enforcement notice. Binding on the addressee or strongly persuasive; not an Act.
- **CONSULT** — draft / consultation / policy paper. **Non-binding.**
- **INDUSTRY** — voluntary industry code.
- **SECONDARY** — law-firm / vendor explainer used only for orientation; **always cross-check** against the primary instrument before reliance.

> **Caveat.** Several sources are **SECONDARY** and are explicitly flagged as such wherever cited in the topic files. Figures that appear *only* in secondary sources or in **CONSULT** drafts are marked **"needs authoritative confirmation"** in the topic files.

## Verification protocol used

1. **Primary-first:** where a statute/regulation figure is available (e.g. R250m `[S1]`), it is preferred over secondary restatements.
2. **Draft ≠ law:** every figure sourced from a **CONSULT** instrument (e.g. payment categories `[S10][S11]`) is explicitly labelled draft/non-binding.
3. **Secondary corroboration:** SECONDARY sources are used only where a primary machine-readable source was not retrievable, and are flagged inline with "— secondary".
4. **Uncertainty honesty:** thresholds that could not be confirmed from a primary source are stated as **"needs authoritative confirmation"** rather than asserted.
