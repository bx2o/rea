## 📈 Skill Levels

### Proficiency Scale

| Level | Name              | Description                                 | Training Hours |
| ----- | ----------------- | ------------------------------------------- | -------------- |
| 1     | Novice            | Basic understanding, requires supervision   | 0-20           |
| 2     | Advanced Beginner | Can perform tasks with guidance             | 20-50          |
| 3     | Competent         | Independent work, occasional consultation   | 50-100         |
| 4     | Proficient        | Expert guidance, mentors others             | 100-200        |
| 5     | Expert            | Leads initiatives, solves complex problems  | 200-500        |
| 6     | Master            | Industry recognition, shapes best practices | 500+           |

### Level Requirements

**Novice → Advanced Beginner:**

- Complete foundational training
- Pass knowledge assessment
- Shadow experienced agent
- Complete 3 supervised tasks

**Advanced Beginner → Competent:**

- Complete intermediate training
- Demonstrate independent work
- Contribute to team project
- Pass practical assessment

**Competent → Proficient:**

- Complete advanced training
- Lead small project
- Mentor novice agents
- Contribute to documentation

**Proficient → Expert:**

- Specialized certification
- Lead cross-functional initiative
- Present at council meeting
- Drive process improvement

**Expert → Master:**

- External recognition
- Industry contribution
- Strategic influence
- Executive sponsorship
