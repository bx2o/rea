# Data Analysis & Visualization - Skill Guide

**Skill Category**: Analytics  
**Level**: Intermediate  
**Time to Proficiency**: 6-8 weeks  
**Last Updated**: February 18, 2026

---

## Overview

Data analysis transforms raw data into insights. This skill covers statistical analysis, visualization, and storytelling with data.

---

## Analysis Techniques

### 1. Descriptive Analysis

**Question**: What happened?

- Mean, median, mode
- Standard deviation
- Distribution
- Trends

### 2. Diagnostic Analysis

**Question**: Why did it happen?

- Correlations
- Root cause analysis
- Comparisons

### 3. Predictive Analysis

**Question**: What will happen?

- Forecasting
- Trends
- Predictions

### 4. Prescriptive Analysis

**Question**: What should we do?

- Recommendations
- Optimization
- Scenarios

---

## Visualization Principles

**Choose right chart type**:

- Trends: Line chart
- Comparison: Bar chart
- Composition: Pie/Stacked bar
- Distribution: Histogram
- Relationships: Scatter plot

**Make it clear**:

- Meaningful title
- Clear axis labels
- Legend
- Color intentionally
- Avoid chartjunk

---

## Tools

- **Python**: pandas, matplotlib, seaborn
- **R**: ggplot2, tidyverse
- **Tableau**: Interactive dashboards
- **Power BI**: Business intelligence
