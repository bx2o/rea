# Growth Hacking Strategies - Skill Guide

**Skill Category**: Business & Growth  
**Level**: Intermediate to Advanced  
**Time to Proficiency**: 8-10 weeks  
**Last Updated**: February 18, 2026

---

## Overview

Growth hacking combines product, marketing, and data. This skill covers rapid user acquisition and retention.

---

## Growth Loops

### Viral Loop

```
User A invites User B
User B gets value
User B invites User C

Example: Dropbox, Slack, Zoom
Viral coefficient: How many new users per user
Target: > 1.0 (exponential growth)
```

### Retention Loop

```
User logs in
Gets value from product
Wants to come back
Habit formation
```

### Monetization Loop

```
Free users
% convert to paid
Increasing revenue per user
Expansion revenue (upgrades)
```

---

## Acquisition Channels

### Organic

- SEO: Long-term, sustainable
- Word of mouth: Viral mechanics
- Content: Blog, YouTube

### Paid

- Ads: SEM, social, display
- Influencers: Authority endorsement

### Partnerships

- Integrations: Other platforms
- Referrals: Incentive programs

---

## Quick Wins

- Optimize conversion funnel (1-2%)
- Reduce friction in signup (30% impact)
- Improve onboarding (20% retention)
- Launch retention program (10-15% churn reduction)

---

## Experimentation Framework

1. Analyze data (where are bottlenecks?)
2. Hypothesis (what could shift metrics?)
3. Experiment (test with small cohort)
4. Measure (did it work?)
5. Scale (roll out winners)
