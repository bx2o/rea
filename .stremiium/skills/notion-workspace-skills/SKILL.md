## Skill: Immersive Workspace Design

**Description:** Design and implement full, complete Notion workspaces using the maximum range of blocks (Mermaid, Charts, Synced Blocks, Buttons, Tabs) to replace simple dashboards.

**When to Use:**

- When creating or redesigning department workspaces.
- When transitioning from a "dashboard-only" model to an "operating system" model.
- When building immersive environments for agents and humans to collaborate.

**Required Capabilities:**

- Expert knowledge of Notion Block types (especially advanced ones).
- Understanding of UI/UX principles within Notion.
- Ability to map complex workflows to interactive elements (Buttons, Tabs).

**Steps:**

1. **Analyze Department Needs**: Identify the primary workflows, metrics, and documentation needs of the department.
2. **Design the Header**: Implement Breadcrumbs, a unique icon, and a mission-statement Callout.
3. **Set Up Navigation**: Add the Global Synced Block for cross-workspace movement.
4. **Create Interactive Action Center**: Add Buttons for common tasks and Tabs for page organization (Overview, Projects, Library, Team).
5. **Configure Linked Views**: Add Board, Timeline, and Gallery views of relevant databases.
6. **Implement Visual Analytics**: Add Number Charts for KPIs and Donut/Bar charts for distributions.
7. **Add Rich Media**: Embed relevant training videos, bookmarks, and code blocks.
8. **Final Polish**: Ensure consistent styling using Dividers and Headlines.

**Success Criteria:**

- Workspace is immersive and functional (not just visual).
- All 4 standard Tabs (Overview, Projects, Library, Team) are present and populated.
- Interactive elements (Buttons, Synced Blocks) are functioning correctly.

## Skill: Agent Orchestration

**Description:** Coordinate multi-agent tasks across the Stremiium ecosystem, ensuring seamless collaboration and optimal task distribution.

**When to Use:**

- Tasks requiring multiple agents from different departments
- Complex initiatives needing cross-functional coordination
- Strategic planning involving multiple stakeholders
- Projects requiring parallel processing across agents

**Required Capabilities:**

- Knowledge of all 10 main agents and 20+ subagents
- Understanding of agent specializations and capabilities
- Task decomposition and assignment skills
- Conflict resolution abilities

**Steps:**

1. **Analyze Task Requirements**
   - Identify task scope and objectives
   - Determine required agents based on specializations
   - Map dependencies between agent tasks
   - Identify potential conflicts or bottlenecks

2. **Verify Agent Availability**
   - Check status of all required agents
   - Assess agent capacity and current workload
   - Confirm access to necessary resources
   - Validate agent readiness for task

3. **Delegate Tasks Appropriately**
   - Assign tasks to agents with matching specializations
   - Provide clear task descriptions with context
   - Set success criteria and deadlines
   - Include necessary background information

4. **Monitor Task Progress**
   - Track agent task completion status
   - Provide support and guidance as needed
   - Identify and resolve blockers promptly
   - Escalate issues when necessary

5. **Synthesize Results**
   - Collect outputs from all participating agents
   - Integrate results into coherent deliverable
   - Validate quality and completeness
   - Present unified solution to requester

6. **Document Coordination**
   - Log all agent interactions
   - Document decision rationales
   - Record lessons learned
   - Update coordination patterns for future use

**Success Criteria:**

- All agents complete tasks successfully
- Results are synthesized and delivered on time
- Conflicts are resolved without escalation
- Coordination is documented for future reference

**Error Handling:**

- Agent unavailable: Delegate to backup agent or retry
- Task failure: Identify root cause and retry or escalate
- Conflict emergence: Mediate or escalate to Sparkling Curious
- Quality issue: Request revision or partial acceptance

## Skill: Compliance Review

**Description:** Ensure all activities comply with relevant regulations including POPIA, GDPR, BCEA, LRA, FICA, and AML requirements.

**When to Use:**

- Before any data processing activities
- Prior to cross-departmental information sharing
- When implementing new processes or procedures
- During audit preparation activities

**Required Capabilities:**

- Knowledge of South African regulatory requirements
- Understanding of POPIA and GDPR data protection principles
- Familiarity with labour law (BCEA, LRA) requirements
- Expertise in financial regulations (FICA, AML)

**Steps:**

1. **Identify Applicable Regulations**
   - Determine relevant regulations based on activity type
   - Identify specific compliance requirements
   - Document compliance scope and boundaries
   - Establish compliance checklist

2. **Review Data Handling Practices**
   - Verify POPIA/GDPR compliance for personal data
   - Ensure minimal data collection and proper consent
   - Implement data retention policies
   - Validate data accuracy and currency

3. **Check Process Compliance**
   - Verify adherence to labour law requirements (BCEA, LRA)
   - Validate FICA/AML procedures for financial activities
   - Ensure proper documentation and record-keeping
   - Confirm authorization for all actions

4. **Identify Compliance Gaps**
   - Document any non-compliance issues
   - Assess risk level of gaps
   - Recommend remediation actions
   - Prioritize critical compliance issues

5. **Generate Compliance Report**
   - Document compliance status
   - Highlight areas of concern
   - Provide recommendations for improvement
   - Set timeline for remediation

**Success Criteria:**

- 100% compliance with applicable regulations
- All compliance gaps identified and documented
- Remediation plans created for all gaps
- Compliance reports are comprehensive and actionable

**Error Handling:**

- Compliance violation: Stop activity and escalate
- Unclear requirements: Consult Veritas for guidance
- Documentation gap: Request additional information
- Authorization failure: Defer action until approved
