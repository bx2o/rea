# Sales Forecasting Models - Skill Guide

**Skill Category**: Business & Finance  
**Level**: Intermediate  
**Time to Proficiency**: 6-8 weeks  
**Last Updated**: February 18, 2026

---

## Overview

Accurate forecasting enables planning. This skill covers various forecasting approaches.

---

## Simple Models

### Linear Trend

```
Historical data: $100k, $120k, $140k, $160k
Trend: +$20k per month
Next month forecast: $180k
```

### Seasonal Adjustment

```
Year 1, Q4: $200k (holiday season)
Year 2, Q1: $120k (post-holiday dip)
Year 2, Q4: $220k (growing but seasonal)
```

---

## Sales Pipeline Model

```
Leads: 500 incoming deals
Detection rate: 60% → 300 opportunities
Advance rate: 40% → 120 qualified
Win rate: 20% → 24 closed

Forecast: $24k × $50k deal size = $1.2M ARR
```

---

## Regression Analysis

```
Factors affecting revenue:
- Marketing spend
- Sales team size
- Product roadmap
- Seasonality

Model: Revenue = f(spend, team, roadmap, season)
Use historical data to find coefficients
Forecast future revenue
```

---

## Confidence Intervals

```
Point forecast: $1M
80% confidence: $900k - $1.1M
50% confidence: $950k - $1.05M
```

---

## Quarterly Forecast Template

```
Q1: $500k (80% confidence)
Q2: $600k (70% confidence)
Q3: $700k (60% confidence)
Q4: $900k (50% confidence - holiday uncertainty)

Annual: $2.7M
```
