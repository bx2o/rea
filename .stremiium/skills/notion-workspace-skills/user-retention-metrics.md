# User Retention & Engagement Metrics - Skill Guide

**Skill Category**: Business & Analytics  
**Level**: Intermediate  
**Time to Proficiency**: 6-8 weeks  
**Last Updated**: February 18, 2026

---

## Overview

Retention is cheaper than acquisition. This skill covers measuring and improving user retention.

---

## Key Metrics

### Retention Rate

```
Retained = Users from period X still active in period X+1
Example: 1000 users in Jan
800 still active in Feb = 80% 1-month retention
```

### Cohort Analysis

```
Cohort: All users in January
Week 1: 100% (100/100)
Week 2: 85% (85/100)
Week 4: 60% (60/100)
Week 8: 40% (40/100)

Shows natural drop-off pattern
```

### DAU/MAU Ratio

```
DAU = Daily Active Users
MAU = Monthly Active Users

High ratio = Engaged users (40%+ good)
Low ratio = Users visit occasionally
```

---

## Engagement Metrics

- Session length
- Feature adoption
- Frequency of use
- Power-user % (top 10% usage)

---

## Churn Prediction

```
Early signals of churn:
- Reduced login frequency
- Stopped using key features
- Downgraded tier

Intervene:
- Proactive support
- Feature training
- Special offers
```

---

## Retention Tactics

- Onboarding: First-time user success
- Progress: Show value quickly
- Engagement: Regular notifications
- Community: User interactions
- Surprise: Unexpected delights
