# Budget Review & Reforecasting Playbook

**Purpose**: Quarterly budget review and adjustment process  
**Trigger**: End of quarter, mid-year review, new strategic initiative  
**Owner**: CFO + Finance Lead  
**Last Updated**: February 18, 2026

---

## Quarterly Reforecasting Cycle

### Week 1: Actuals & Reconciliation

```
- Close books for previous quarter
- Reconcile all budget vs actual
- Identify variances (> 10% flag for review)
- Calculate burn rate
- Assess cash position
```

### Week 2: Departmental Forecasts

```
Each department head submits:
- Q1 actuals (final)
- Q2 actuals (if in Q2)
- Q3-Q4 forecasts (updated)
- New initiatives requested
- Resource needs
```

### Week 3: Finance Analysis

```
- Consolidate forecasts
- Identify risks/opportunities
- Model scenarios
- Assess headcount needs
- Review spending patterns
```

### Week 4: Executive Review & Decision

```
- Finance presents to leadership
- Go/no-go on initiatives
- Budget adjustments approved
- Communication to teams
- Updated budgets distributed
```

---

## Decision Framework

### For Each Initiative

**Calculate ROI**:

```
Expected Revenue / Investment = ROI
or
Cost Savings / Investment = ROI

Typically want >3:1 ROI
```

**Assess Risk**:

```
High confidence: Fund fully
Medium confidence: Fund 50%, revisit
Low confidence: Fund pilot only
```

**Prioritize**:

```
Go/no-go scoring matrix
Consider strategic fit
Consider resource availability
Consider cash position
```

## Budget Variance Analysis

### Investigation Template

```
Category: Advertising
Budget: $100k
Actual: $150k
Variance: +50% over

Analysis:
- Why did we spend more?
- Did we get proportional return?
- Was it a good decision?
- Should we adjust forward forecast?

Actions:
- Approve overage? Yes/No
- Adjust Q3-Q4 forecast? How?
- Change process? Yes/No
```

---

## Scenario Planning

### Case 1: Revenue Miss

```
If revenue is 20% below forecast:
- Cut discretionary spending: 5-10%
- Slow hiring: Defer non-critical roles
- Extend timeline: Push projects to next quarter
- Preserve: Core product, sales capacity
```

### Case 2: Unexpected Opportunity

```
If major customer comes in requiring:
- Reallocate 10% of engineering
- Hire contractor support
- Accelerate infrastructure
- Defer lower-priority projects
```
