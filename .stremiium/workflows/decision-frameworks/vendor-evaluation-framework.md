# Vendor Evaluation & Selection Framework

**Purpose**: Systematically evaluate and select vendors/partners  
**Use When**: Choosing SaaS tools, hiring agencies, picking infrastructure providers  
**Owner**: The Engineer + Procurement Team  
**Last Updated**: February 18, 2026

---

## Evaluation Criteria

### Product/Service Quality

- Feature completeness? (1-10)
- Performance/reliability? (1-10)
- Security & compliance? (1-10)
- Integrations available? (1-10)

### Financial

- Pricing transparent?
- Cost vs. alternatives?
- Total cost of ownership?
- Payment terms?

### Company Viability

- Financially stable?
- Roadmap compelling?
- Customer references available?
- Growth trajectory?

### Support & Relationship

- Response times documented?
- Training available?
- Dedicated account manager?
- Community size?

### Risk Assessment

- Vendor lock-in risk?
- Data security concerns?
- Contract terms fair?
- Exit strategy clear?

---

## Selection Process

1. **Research** (1 week)
   - Identify 5-10 candidates
   - Initial vetting
   - Request demos

2. **Evaluation** (2 weeks)
   - Deep dive on top 3
   - Score using matrix
   - Get customer references
   - POC if needed

3. **Negotiation** (1-2 weeks)
   - Pricing discussion
   - Contract review
   - SLA negotiation
   - Implementation terms

4. **Decision** (1 week)
   - Final scoring
   - Team consensus
   - Executive approval
   - Signed contract

## Red Flags

```
🚩 Unclear pricing
🚩 No references available
🚩 Startup with <$5M revenue (unstable)
🚩 High lock-in, no data export
🚩 Poor communication
🚩 Unrealistic promises
🚩 Hostile contract terms
```
