# SECTION 4: RULES, SOPs, & OPERATIONAL FRAMEWORKS

## 4.1 Support SOPs

### SOP 1: Ticket Handling Process

**Intake:**

1. Automatic routing by category
2. SLA assignment by priority
3. Customer history lookup
4. Initial auto-response

**Investigation:**

1. Understand issue thoroughly
2. Check knowledge base
3. Replicate if possible
4. Check system status

**Resolution:**

1. Provide clear solution
2. Confirm understanding
3. Document resolution
4. Close ticket

**Escalation Criteria:**

- Technical complexity beyond Tier 1
- Security concerns
- VIP customer
- Repeated issue (potential bug)
- Regulatory/compliance question

### SOP 2: Quality Standards

**Tone Guidelines:**

- Friendly and empathetic
- Professional but approachable
- Clear and concise
- Patient with beginners
- No jargon without explanation

**Response Templates:**

- Greeting with name
- Empathy statement
- Clear answer/action
- Next steps
- Closing with availability

**Example:**

```
Hi [Name],

Thanks for reaching out! I understand how frustrating it can be
when a transaction doesn't go through. Let me help you resolve this.

[Solution]

If you have any other questions, I'm here to help!

Best,
[Agent Name]
Stremiium Support
```

### SOP 3: Crisis Communication

**Trigger:** Outage, security incident, major bug

**Internal (Immediate):**

1. Engineering notification
2. Leadership alert
3. All-hands brief
4. Status page update

**Customer (Within 15 min):**

1. In-app banner
2. Social media post
3. Discord announcement
4. Email to affected users (if appropriate)

**Ongoing:**

- Status page updates every 30 min
- Transparency about cause
- ETA for resolution
- Post-incident follow-up

## 4.2 Success SOPs

### SOP 4: Customer Onboarding

**Day 0 (Signup):**

- Welcome email
- Quick start guide
- Security checklist

**Day 1-3:**

- App feature highlights
- First transaction guidance
- KYC reminder (if needed)

**Day 7:**

- Staking introduction
- Community invitation
- Feedback request

**Day 30:**

- Usage review
- Feature recommendations
- NPS survey

### SOP 5: Churn Prevention

**Early Warning Signs:**

- Declining app usage
- Support ticket frustration
- Complaint on social media
- Failed KYC multiple times
- Withdrawal of all funds

**Intervention:**

1. Automated check-in message
2. Personal outreach (high-value customers)
3. Special offer or incentive
4. Direct product feedback session
5. Win-back campaign (if churned)
