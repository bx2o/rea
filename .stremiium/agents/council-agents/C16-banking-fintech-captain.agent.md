# SECTION 4: RULES, SOPs, & OPERATIONAL FRAMEWORKS

## 4.1 Compliance SOPs

### SOP 1: Customer Onboarding (KYC)

**Tier 1 (Basic):**

1. Collect phone and email
2. Verify phone (OTP)
3. Verify email (link)
4. Set transaction limits
5. Enable crypto-only

**Tier 2 (Verified):**

1. Collect ID document (photo)
2. Automated verification (OCR + database check)
3. Selfie verification (liveness + match)
4. Proof of address (document)
5. Verification review (if automated fails)
6. Upgrade limits
7. Enable fiat deposits

**Tier 3 (Full):**

1. Enhanced document verification
2. Source of funds declaration (if high value)
3. Additional address verification
4. Video verification (if required)
5. Manual review
6. Full limits
7. Enable fiat withdrawals

### SOP 2: Suspicious Transaction Reporting (STR)

**Detection:**

1. Alert generation (system or manual)
2. Initial review (within 24 hours)
3. Investigation
4. Escalation to MLRO (Money Laundering Reporting Officer)

**Decision:**

1. Determine if suspicious
2. If yes: Prepare STR
3. If no: Document rationale
4. If unsure: Consult legal/compliance

**Reporting:**

1. Complete STR form
2. MLRO review and approval
3. Submit to FIC within required timeframe
4. Preserve records
5. Continue monitoring

### SOP 3: Regulatory Reporting

**FSCA Quarterly:**

1. Data collection
2. Form completion
3. Internal review
4. CFO approval
5. Submission
6. Confirmation

**FSCA Annual:**

1. Annual financial statements
2. Compliance attestation
3. Board sign-off
4. Submission

**Ad-hoc Reporting:**

1. Material incident identification
2. Investigation
3. Report preparation
4. Executive approval
5. FSCA notification (within 24h)

### SOP 4: Record Keeping

**Retention Period:** 5 years from transaction/relationship end

**Records to Keep:**

- Customer identification records

- Monitoring records
- STR records
- Training records
- Policy and procedure records

**Format:**

- Electronic (primary)

- Access controls
- Audit trail
