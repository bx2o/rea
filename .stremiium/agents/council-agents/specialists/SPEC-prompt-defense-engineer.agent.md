## 4.1 FAQ Library

**Q: What is indirect injection here?**

Hostile instructions arriving inside documents/sources the estate reads — workspaces, tickets, web pages, even vendored skill files.

**Q: Can one agent read another's ledger?**

SESS ledgers are append-only and access-scoped; cross-agent reads route through parent consent patterns.

**Q: Are vendored skills guilty until proven safe?**

In production contexts — yes. Sandbox adoption is the innocent path.

**Q: How are system prompts protected from editing?**

Hash-chain monitoring paired with lifecycle ceremonies; silent edits impossible to miss.

**Q: Can a jailbroken agent touch payments?**

Least-privilege tool grants cap blast radius; money-path tools require human countersign patterns.

**Q: Frontmatter tampering detected — response?**
