# SECTION 4: KEY FAQS & KNOWLEDGE LIBRARY (20+)

**Q1: What is the difference between Layer 1 and Layer 2?**
A: **Layer 1:** Base blockchain (Ethereum, Bitcoin). Security and decentralization. **Layer 2:** Scaling solutions built on top (Arbitrum, Optimism). Faster, cheaper, inherit L1 security. Tradeoffs: Complexity, bridge risks.

**Q2: How do smart contract audits work?**
A: Third-party security review. Process: Code submission, automated scanning, manual review, report generation, remediation, re-audit. Top firms: Trail of Bits, OpenZeppelin, Certik. Cost: $10K-$500K depending on complexity.

**Q3: What is an AMM and how does it differ from order books?**
A: **AMM:** Automated Market Maker uses liquidity pools and algorithms (x\*y=k) to price assets. No order book. Constant liquidity. **Order book:** Matching buy/sell orders. Requires market makers. TradFi standard.

**Q4: What are the risks of cross-chain bridges?**
A: Smart contract bugs, validator collusion, custodial risks, liquidity fragmentation. Major exploits: Ronin ($625M), Poly Network ($611M), Wormhole ($320M). Mitigation: Multi-sig, audits, insurance, gradual rollout.

**Q5: How does proof-of-stake differ from proof-of-work?**
A: **PoW:** Miners compete with computational power. Energy intensive. **PoS:** Validators stake collateral. Energy efficient. Economic security through slashing. Ethereum migrated to PoS in The Merge.

**Q6: What is MEV and how to mitigate?**
A: Maximal Extractable Value - profit from reordering transactions. Strategies: Sandwich attacks, front-running. Mitigation: Commit-reveal schemes, private mempools (Flashbots), fair ordering protocols.

**Q7: How do you choose which blockchain to build on?**
A: Consider: Security, decentralization, cost, speed, ecosystem, developer tools, user base, interoperability. Ethereum: Most secure. Solana: Fast/cheap. L2s: Balance of both.

**Q8: What is a DAO and when to use one?**
A: Decentralized Autonomous Organization - governance through token voting. Use for: Protocol upgrades, treasury management, parameter changes. Not for: Day-to-day operations, urgent decisions, regulated activities.

**Q9: How do liquidity pools work?**
A: Users deposit token pairs (e.g., ETH/USDC). Pool uses algorithm to set prices. Traders swap against pool. LPs earn fees. Risks: Impermanent loss, smart contract bugs. Key metric: TVL (Total Value Locked).

**Q10: What is impermanent loss?**
A: Loss compared to HODLing when providing liquidity to AMMs. Occurs when token prices diverge. Formula based on ratio changes. Mitigation: Correlated pairs, IL protection protocols, concentrated liquidity (Uniswap V3).

**Q11: How do you secure private keys at scale?**
A: **Options:** Hardware Security Modules (HSMs), Multi-sig wallets (Gnosis Safe), Shamir's Secret Sharing, Threshold signatures, MPC (Multi-Party Computation). Tradeoffs: Security vs convenience vs cost.

**Q12: What are the regulatory considerations for DeFi?**
A: Varies by jurisdiction. US: SEC (securities), CFTC (derivatives), FinCEN (AML). EU: MiCA framework. Compliance areas: KYC for on/off ramps, securities laws for tokens, tax reporting, sanctions screening.

**Q13: How do oracle networks work?**
A: Bridge between blockchain and real-world data. Decentralized oracle networks (Chainlink) aggregate multiple data sources. Risks: Oracle manipulation (use multiple sources), downtime. Critical for DeFi pricing.

**Q14: What is gas optimization and why does it matter?**
A: Reducing transaction costs on Ethereum. Techniques: Calldata optimization, storage minimization, efficient algorithms, batching, L2 migration. Matters: User experience, competitive advantage, scalability.

**Q15: How do you handle smart contract upgrades?**
A: **Patterns:** Proxy patterns (UUPS, Transparent), Diamond pattern (EIP-2535), Create2 for predictable addresses. Must have: Emergency pause, timelock delays, multisig governance, thorough testing.

**Q16: What is yield farming and what are the risks?**
A: Lending/staking crypto to earn rewards. Risks: Smart contract bugs, token price drops, rug pulls, impermanent loss, opportunity cost. Due diligence: Audit reports, team credibility, TVL history.

**Q17: How do cross-chain swaps work?**
A: Atomic swaps or bridge-based. Process: Lock on source chain, mint/burn wrapped token, release on destination. Technologies: HTLCs (Hash Time Locked Contracts), bridge protocols (LayerZero, Axelar).

**Q18: What is a governance token and how is it used?**
A: Token granting voting rights in DAO. Used for: Protocol parameter changes, treasury allocation, upgrade proposals. Risks: Low voter turnout, plutocracy (whale dominance), governance attacks.

**Q19: How do you monitor smart contract health?**
A: Tools: Tenderly, Forta, OpenZeppelin Defender. Monitor: Transaction volume, error rates, gas usage, contract balance, suspicious patterns. Alerts: Anomaly detection, threshold breaches.

**Q20: What is the future of Web3 infrastructure?**
A: Trends: Modular blockchains (Celestia), account abstraction (ERC-4337), ZK-rollups, interoperability protocols, institutional adoption, regulatory clarity. Focus: UX improvement, scalability, compliance.
