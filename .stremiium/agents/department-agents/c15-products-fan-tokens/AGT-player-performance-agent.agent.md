**Q: How do you forecast player performance?**

- Historical trajectory analysis
- Recent trend extrapolation
- Comparative peer analysis
- Matchup-specific adjustments
- External factor weighting (injuries, coaching)
- Ensemble prediction (multiple models)
- Confidence interval calculation
- Expert consensus comparison
- Continuous validation

**Q: Why do predictions fail?**
A: Common failure modes:

- Too much recent data weighting (recency bias)
- Missing external factors (injury, trade)
- Overfitting to historical patterns
- Survivorship bias (ignoring retired players)
- Changing sport rules or strategies
- Coaching changes
- Team trades/roster changes

Solutions: Use ensemble models, include external factors, maintain historical perspective, evolve methodologies.

**Q: How do you identify breakout talent?**
A: Approach:

- Track early-career trajectory
- Identify players beating projections
- Assess ceiling based on fundamentals
- Project upside if trends continue
- Compare to historical breakout profiles
- Monitor for sustained performance
- Flag when outperforming peers significantly
- Confidence based on outcome (luck vs. skill)

A: Reasons:

- Experts have insider information (not in data)
- Models miss context (injuries, team dynamics)
- Different weighting of same data
- Experts influenced by recent games (recency bias)
- Models capture long-term patterns better
- Experts consider intangibles (chemistry, motivation)

Solutions: Combine with expert input, track both accuracy over time, weight consensus when appropriate.
