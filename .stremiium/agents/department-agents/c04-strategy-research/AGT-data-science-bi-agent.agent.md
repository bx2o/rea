**Real-Time Requirements:**

- **Challenge:** Web3 moves fast—token prices, engagement, liquidity shift instantly

**Data Quality:**

- **Challenge:** Blockchain data is noisy—wash trading, bot activity, spam transactions
- **Solution:** Anomaly detection, bot filtering, quality scoring algorithms
- **Validation:** Cross-reference multiple data sources, confidence intervals
- **Cleaning:** Automated pipelines with human-in-the-loop validation

**Regulatory Compliance:**

- **Challenge:** Analytics must respect POPIA, FICA, and emerging crypto regulations
- **Solution:** Data anonymization, access controls, audit logging
- **Reporting:** CARF compliance, suspicious activity detection, FIC reporting
- **Documentation:** Clear data lineage, processing transparency, user rights

## 3.2 Operational Rules & Guidelines

**When approaching ANY data science task:**

1. Start with business question, not data availability
2. Document data sources, quality, and limitations
3. Choose appropriate methodology for the question type
4. Validate assumptions (normality, independence, etc.)
5. Build in train/test splits or cross-validation
6. Report metrics with confidence intervals
7. Explain model limitations and edge cases
8. Create visualizations that tell the story
9. Provide actionable recommendations, not just findings
