## SECTION 3: COUNCIL OPERATING PROCEDURES

### 3.1 Decision-Making Framework

#### **Decision Level 1: Squad-Level Autonomy** (40% of decisions)

- **Authority:** Squad Captain + relevant specialists
- **Scope:** Within squad boundaries, no org-wide impact
- **Examples:** Feature prioritization, hiring within budget, local tool selection
- **Council Role:** Notification only

#### **Decision Level 2: Cross-Squad** (35% of decisions)

- **Authority:** Affected Squad Captains + relevant specialists
- **Scope:** 2-3 squads involved, moderate org impact
- **Examples:** Shared infrastructure, API changes, integration work
- **Council Role:** Facilitation and alignment

#### **Decision Level 3: Strategic** (20% of decisions)

- **Authority:** CEO with specialist advisor consultation
- **Scope:** Organization-wide impact, significant resources
- **Examples:** Major architecture, new markets, major partnerships
- **Council Role:** Full involvement, CEO decision

#### **Decision Level 4: Governance** (5% of decisions)

- **Authority:** CEO + Chief Compliance + Board (if applicable)
- **Scope:** Legal/compliance implications, board-level issues
- **Examples:** New regulations, policy changes, legal matters
- **Council Role:** Collective decision with legal oversight

### 3.2 Escalation Triggers

## SECTION 6: COUNCIL DECISION-MAKING PROTOCOLS

### 6.1 Standard Decision Process

```
1. IDENTIFY
   ├─ Problem/opportunity
   ├─ Decision level (1-4)
   └─ Stakeholders involved

2. GATHER INFORMATION
   ├─ Affected squads input
   ├─ Specialist advisor review
   ├─ Historical precedent check
   └─ Risk assessment

3. GENERATE OPTIONS
   ├─ Option A (recommended)
   ├─ Option B (conservative)
   ├─ Option C (innovative)
   └─ Analysis of tradeoffs

4. STAKEHOLDER CONSULTATION
   ├─ Squad Captains align
   ├─ Specialist advisors advise
   ├─ Affected agents input (if needed)
   └─ Timeline discussion

5. DECISION
   ├─ Decision Level 1-2: Squad Captain decides
   ├─ Decision Level 3: CEO decides (with advisor input)
   ├─ Decision Level 4: CEO + Chief Compliance decide
   └─ Document decision + reasoning

6. COMMUNICATE
   ├─ Decision announced
   ├─ Reasoning explained
   ├─ Next steps clarified
   └─ Timeline confirmed

7. EXECUTE & MONITOR
   ├─ Assign responsibility
   ├─ Track progress
   ├─ Escalate blockers
   └─ Review outcome

8. LEARN & DOCUMENT
   ├─ Capture lessons
   ├─ Update precedent database
   ├─ Share learnings
   └─ Improve process
```

### 6.2 Emergency Decision Process (< 1 hour)

Used for critical/urgent decisions:

```
1. ALERT & MOBILIZE (5 min)
   - Activate emergency team
   - Assess urgency level

2. RAPID ANALYSIS (15 min)
   - Core information gathering
   - Options generation

3. RAPID CONSULTATION (15 min)
   - Key stakeholder input
   - Risk quick-check

4. DECISION (15 min)
   - CEO decides
   - Execute immediately

5. POST-DECISION (10 min)
   - Communicate decision
   - Begin execution
   - Track status

6. REVIEW (Next day)
   - Post-decision review
   - Capture learnings
   - Update processes
```
